# *QuizDaTI*

##  Sobre o projeto

O QuizDaTI é um sistema de Quiz que desenvolvemos para testar conhecimentos na área de Tecnologia da Informação.

O projeto foi desenvolvido em *C# com Windows Forms* e utiliza *PostgreSQL* para armazenar os dados.

##  Tecnologias

- C#
- Windows Forms
- PostgreSQL
- Trello
- Figma
-  GitHub

##  Funcionalidades

-  Login e cadastro de usuários
-  Quiz com perguntas e alternativas
-  Sistema de pontuação
-  Visualização de resultados
-  Histórico de respostas
-  Ranking
-  Resultado
-  Área administrativa

##  Banco de dados

O PostgreSQL armazena informações de usuários, perguntas, respostas, pontuação e histórico.

As senhas são protegidas utilizando *BCrypt*.

##  Como executar

1. Instale o Visual Studio e PostgreSQL.
2. Configure o banco de dados.
3. Abra o projeto no Visual Studio.
4. Verifique a conexão com o PostgreSQL.
5. Execute o projeto.
